## Limitations and execution conditions

1. **Writers must be closed.** The helper's lock coordinates this helper only; it does not acquire the old Linux packager's `fcntl` lock or stop other writers. Repeated hashes detect observed changes, but pathname checks and hashing are not a transactional snapshot or protection against a hostile concurrent filesystem mutation. Root's explicit closed-writer confirmation remains necessary.
2. **No runtime result is admitted here.** Neither the no-argument helper, actual backup/candidate creation, nor any archive verification was run. Existing CPU84 mesh/ZIP QA was not repeated. Actual success must be established by the helper's completed receipt and preserved entry manifest after root authorizes execution.
3. **Private implementation dependency is bounded.** Runtime guards pin interpreter version/path, not the `zipfile` source hash. This review binds the installed source hash above. Reopened metadata/raw/content checks fail before publication if this writer normalizes a case attribute. The archive's central-directory byte stream and absolute record offsets are intentionally not preserved.
4. **Backup and failure semantics are accurately limited.** A Windows readonly attribute is not an immutable storage guarantee. `fsync` plus `os.replace` provides a verified same-directory replacement, not a power-loss transaction for every filesystem state. A failure after replacement leaves the verified candidate at the compact path and the old backup for manual review; failure logging is best effort. Root should inspect a reported postpublication failure rather than assume automatic rollback. A stale helper lock requires manual review; it is not automatically removed at startup.
5. **Study metadata differs from preserved case metadata.** Refreshed `study/**` entries use native `ZipInfo.from_file`; their bytes and membership are checked, but their old Linux ZipInfo/Unix executable modes are not retained. The explicit preservation contract and equality checks cover all old `cases/**` entries.
