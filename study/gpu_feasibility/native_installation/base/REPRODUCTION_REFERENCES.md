Their original workspace was `work/native_stdpar_install/`, `work/native_cpu_control/` or `work/strict_cavity_v2/`; private install prefixes remain recorded in each file. The wrapper below explains curation and later outcomes without rewriting historical code or receipts as a run performed from this package. Earlier READMEs/proposed-state wording are creation-time history, not current status. SDK binaries and full upstream trees are external pinned prerequisites.

Exact dependency aliases are copied beside CPU/GPU/strict recipes. Other absolute references to full upstream trees, private SDK/tool installations, old completed cases and full raw profiler files remain deliberately external. The provenance inventory maps included copies back to originals; a path in a historical receipt is not a requirement to overwrite that original.

For a fresh reproduction, inspect these procedures in order: verify external SDK/source/tool bytes; configure only fresh task-owned prefixes; apply pinned rule/backport/scoped link changes; build with an appropriate bounded job/memory budget; run explicit compiler/device/framework checks; then prepare a new separately approved strict fixture with new immutable freeze/child/library evidence. The original main build helper also runs its stock cavity, whose historical screen failed; do not interpret a completed build as that screen passing. No new-host run, rebuild or performance measurement has been executed by curation.
